✅ **Front Post Board** - Community message board with threaded discussions and dynamic content

✅ **Games Module** - Including **AstroMiner**, a fully functional 3D space mining game embedded in the BBS (built with C++/Raylib, integrated via DLL)

✅ **Team Info** - Character bios and dossiers for the hacker group members

✅ **Pirate Radio** - Underground radio module (audio playback coming soon)

✅ **Token System** - Progression system that unlocks content based on player actions

✅ **Steam Integration** - Ready for achievements, stats, and cloud saves

**The World:**

Set in an alternate 1989 where Japan was annexed by the US after Hiroshima destroyed the Imperial Family. You're part of an underground hacker group trying to reclaim a heritage they never knew. The political backdrop adds weight to every interaction.

- Built with Python/Pygame for the main BBS interface
- C++ mini-games compiled as DLLs for performance
- Keyword-based NLP for NPC responses (no external APIs needed)
